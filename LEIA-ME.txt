CHESS UP — PROJETO UC7

O Chess Up é uma demonstração visual responsiva de uma plataforma de xadrez, desenvolvida com HTML5 e CSS3. Esta versão não utiliza JavaScript.

DOCUMENTAÇÃO
- README.md: documentação principal do projeto, tecnologias, telas, execução, limitações e status.
- suporte.html: manual de navegação para quem visita o site.

ARQUIVOS DO PROJETO
- index.html: página de entrada; redireciona para home.html.
- home.html: página inicial, tabuleiro demonstrativo, desafios, partidas e conteúdo de aprendizado.
- sobre.html: página de apresentação do desenvolvedor.
- suporte.html: página de suporte com perguntas e respostas em acordeões HTML.
- style.css: identidade visual, responsividade, menu móvel e estilos das páginas.
- logo-chessup.png: logotipo utilizado no site.
- avatar.jpg: imagem de perfil utilizada na página Sobre mim.

COMO EXECUTAR
1. Abra index.html em um navegador; ou
2. Abra a pasta no Visual Studio Code e utilize o Live Server.
3. Mantenha os arquivos HTML e style.css na mesma pasta, junto de logo-chessup.png e avatar.jpg.

LIMITAÇÕES
O tabuleiro, os modos de jogo, os controles, os desafios, o histórico e as estatísticas são ilustrativos. Esta versão não executa jogadas, partidas, validações, armazenamento de resultados, partidas online ou jogo contra computador.

A página de suporte explica como navegar pelas áreas disponíveis e diferencia os elementos demonstrativos das funções que ainda não estão implementadas.
